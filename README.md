# 🚀 InboxCopilot AI — Landing Page

> **Turn Your Facebook Inbox Into Your AI Sales Copilot**
> AI analyzes customer conversations, identifies high-intent buyers, finds lost sales opportunities, and tells you what to do next.

Built specially for Bangladeshi and global conversational commerce & F-commerce sellers.

---

## 🌟 Key Features Included

1. **High-Converting Hero Section**: Compelling headline, interactive mini-chat scanner, and quick CTA buttons.
2. **Interactive Revenue Leakage Calculator**: Lets sellers slide their monthly conversation volume and see potential lost revenue and recoverable earnings in BDT (৳).
3. **"See AI in Action" Live Demo**: Switchable scenarios (Fashion shop, Gadgets store, Cosmetics brand) demonstrating real Banglish conversation intent classification and automated response script recommendations.
4. **Step-by-Step "How It Works"**: Simple 3-step setup guide (Connect ➔ AI Analyzes ➔ Actionable Insights).
5. **6 Core Features Grid**: Hot lead scoring, conversation intelligence, drop-off detection, objection analysis, sales trends, and AI recommendations.
6. **Executive Dashboard Mockup**: Real-time sales metrics, reason breakdown table (price, delivery, size, ghosting), and urgent hot lead queue.
7. **Free AI Analysis Lead Capture Engine ⭐⭐⭐**: Full lead capture form with instant simulated AI audit report modal and persistent local storage.
8. **Founding Member Early Access**: Early bird cohort progress bar and VIP perks.
9. **FAQ Accordion**: Comprehensive answers on Banglish compatibility, chatbot differences, data privacy, and launch timeline.

## 🚀 How to Deploy to Vercel

### Option 1: Direct Vercel CLI
```bash
npm install -g vercel
vercel
```

### Option 2: GitHub / Git Deployment
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of InboxCopilot AI Landing Page"
   git branch -M main
   git remote add origin https://github.com/your-username/inboxcopilot-landing.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) ➔ Click **Add New Project** ➔ Import the GitHub repository ➔ Click **Deploy**.
3. Your landing page is live in seconds!
